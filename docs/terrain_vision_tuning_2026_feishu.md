# Mengde 地形视觉模型调优方案与首轮实验

## 结论

当前瓶颈不是 DINOv3 不够强，而是监督数据混入了与地图图像不一致的 Lua 弱标签。旧模型在这些标签上训练后，草地、山地和大河的 F1 归零；继续堆模型规模只会更快地拟合错误答案。

首轮调优已新增可信自然地形旁路模型：冻结 DINOv3 特征，使用余弦适配头、类别均衡 Focal、遮挡一致性、多原型分类和选择性拒答。它只处理 `平原/草地/树林/山地`，不会覆盖城墙、栅栏、营寨、城池或河流的结构规则。

## 采用的前沿技术

|---|---:|---:|---|
| pooled 宏 F1 | 0.2939 | 0.85 | 失败 |

结论：不生产晋级。联合两图后的空间分块选择性准确率仍有 0.9898，但跨整图只有 0.5333，说明模型明显依赖同源纹理。草地和山地在跨图测试中召回为零，必须先解决域偏移。production_promotion=false、auto_apply=false 保持不变。

下一轮不能再靠增加树深或训练轮数。应增加第三张不同美术来源的完全复核图，并优先采用地图级风格归一化、类条件原型对齐和目标图置信校准；所有改动仍以整图留一成绩作为唯一晋级依据。

### 1. 冻结 DINOv3 密集特征

DINOv3 专门改善了长训练后密集特征退化问题，适合作为山林纹理的通用骨干。本项目保留冻结骨干，只训练轻量适配头，3060 12GB 可以稳定运行，也降低小数据过拟合风险。

### 2. 多原型而非单中心

一类地形可能有多个外观簇，例如稀林、密林、雪林、岩山和草坡。每类先聚成多个原型，再取最相近的若干原型做投票。这个设计参考了原型对比域适配的思路，避免一个平均原型把山地和树林抹成同一团。

### 3. 遮挡一致性

训练时对同一特征做两次随机遮挡，要求两个预测一致。它是 MIC 思路在特征层的轻量化实验，不等同于完整的 EMA teacher MIC。完整 MIC 应在后续有更多未标注真实地图时加入。

### 4. 稀有类均衡

采样器对每类做逆频率采样，并使用 Focal 调低容易样本的权重。这和 DAFormer 的 Rare Class Sampling 目标一致：先阻止多数类平原吞掉草地和山地，再讨论整体精度。

### 5. 选择性预测

余弦分类头和多原型头必须同意，同时置信度及第一、第二名间隔达到阈值才接受。其余格进入复核队列。错误自动标注的成本高于少标，因此生产目标应优先优化选择性准确率，而不是强行 100% 覆盖。

## 不建议直接接入的模型

- SAM2：适合勾边和生成 mask，但不负责区分山地、丘陵、树林，不能单独当分类器。
- 开放词汇 CLIP 分割：通用文字语义强，但对 MOD 风格的平原/草地细粒度纹理区分通常不如少量可信原型。
- 单独 AnyUp/ViT-Up/FeatUp：改善边缘和密集特征分辨率，不能修复错误标签；应放在分类正确之后做边缘精修。
- 遥感基础模型：对真实卫星影像有效，但游戏地图存在手绘风格域差异，必须先做小规模对照实验，不应直接替换 DINOv3。

## 下一阶段验收

1. 从不同美术来源选第二、第三张地图，每张复核至少 200 个纯自然格，并按整图留一法验证。
2. 用 RIPU 的区域不纯度加预测不确定度选择待复核区域，优先标注山林交界和草地/平原混淆区。
3. 对未标注目标地图加入 EMA teacher 的完整 MIC，只使用高置信且双头一致的伪标签。
4. 自然地形达到跨地图宏 F1 0.85、每类召回 0.75、选择性准确率 0.98 后才允许晋级。
5. 结构分支继续独立验收：城墙/栅栏/大河不可跨越，城池/营寨可补给，小河可通过；任何视觉模型不得覆盖人工确认的结构格。
