# orgFlow 军府记功闭环

东周官署过去只能从 orgFlow 阵容快照读取军府贡献，裁可属官复命时只结算公共库藏，未把本次组织贡献写回成长账。现在复命裁可形成以下权威链路：

1. orgFlow 返回终态差事结算，NexusKernel 先封存结案印记并等待玩家裁可。
2. 玩家裁可后，网关以结算号为幂等来源写入公共库藏，再调用 orgFlow 正式 `growth-credits` 接口记入同额成长贡献。
3. `dongzhou_mandate_workflow 1.8.0` 将结算号、任务号、结案印记、累计贡献、账本版本和 NexusKernel 版本封成记功印记。
4. 浏览器仅在记功印记与待裁结算完全一致时更新军府贡献；后续任务对账使用 orgFlow 返回的累计值，不再本地重复累加。

若第二段记功暂时失败，裁可记录保持可重试。公共库藏和成长贡献分别使用稳定幂等键，重试不会在 orgFlow 账本重复入账。申斥不会发放库藏或成长贡献，原有 AINPC 好感、经历和记忆后果保持不变。

orgFlow 的记功入口只接受 `organizations.v12.growth.credit` 专用签名权限，服务身份还绑定游戏服务器 `91001`，保留原有跨服隔离。旧版本已经裁可但尚无记功印记的结算会在读取时按结算号懒迁移；迁移成功后封存同一份权威累计值，服务暂不可用时则保留原记录并等待下次幂等重试。
