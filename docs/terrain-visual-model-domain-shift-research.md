# 地形纯视觉模型整图留一优化调研

## 结论

当前 `0.2958` 主要不是边缘上采样问题，而是两张完整复核地图不足以构成跨域训练集：留出 `m058` 时，训练侧真实地图没有草地真值，纯山地仅 14 格；因此草地、山地召回均为 0。纹理图虽补了草地数量，却不等于补了目标地图画风。

严格整图留一要求：按地图分组；留出图标签只能在预测结束后计分；目标位图可用于无标签统计；任何缺类或召回为 0 都禁止晋级。

## 论文与项目映射

1. **DAFormer / Rare Class Sampling**：先解决草地、山地训练支持不足和伪标签确认偏差。项目：https://github.com/lhoyer/DAFormer
2. **MixStyle**：只在多个源地图之间混合浅层风格统计，保留原始内容分支。项目：https://github.com/KaiyangZhou/mixstyle-release
3. **Semantic-Aware Normalization / Whitening**：按类别对齐特征，避免全图归一化把树林、山地混在一起。
4. **MIC**：第三张复核图加入后，用 EMA 教师、0.8 以上伪标签及掩码一致性增强目标上下文；当前代码只有特征遮挡，不能称完整 MIC。
5. **EATA / SAR**：若做测试时适配，必须过滤不可靠样本并限制漂移。禁止直接做裸熵最小化，避免类别不平衡下单类坍缩。
6. **FSSDINO**：比较 DINOv3 中间层，但层号只能由训练侧空间块选择；禁止用留出图标签做 Oracle 选层。
7. **FDA**：可作为源图到目标图的低频风格增强消融，但必须保留源标签几何且与 MixStyle 同基准比较。
8. **AnyUp / ViT-Up / FeatUp**：只用于分类正确后的边缘细化，不负责修复草地、山地类别召回为 0。

## 实施顺序

1. 增加至少第三张独立画风的完整复核地图。每类至少 100 个纯格，且每类覆盖至少两张源地图；结构类继续独立处理。
2. 复核图必须满足像素语义与矩阵一致。生成器规则矩阵、透明色罩和 `reviewed` 字段都不能替代逐格视觉复核。
3. 三图 LOMO 先跑全特征线性探针、当前适配器和 DINO 中间层训练侧选择。
4. 再加入源域均衡采样、MixStyle 和语义感知归一化；逐项消融，不同时堆叠。
5. 最后才尝试 MIC/EATA 式无标签目标适配。伪标签需置信度、原型一致性和邻域一致性三重门控。

## 晋级门槛

- 整图留一 pooled macro F1 >= 0.85
- 每类召回 >= 0.75
- 选择性准确率 >= 0.98，覆盖率 >= 0.50
- 任一地图明显回归、任一类别召回为 0、或使用留出标签调参，均禁止生产晋级和自动写回 Lua
