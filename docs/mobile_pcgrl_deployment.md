# 麻隧演武：手机端 PCGRL 交付说明

## 交付边界

- 主线仍为 172 关；麻隧演武不注册为第 173 关。
- 史实骨架采用《左传·成公十三年》：前 578 年晋厉公会诸侯伐秦，晋军四军将佐参战，秦师败绩，成差与不更女父被获，联军渡泾至侯丽而还。
- 史料没有给出可复原的格级地形和逐回合阵形。地图、障碍与部署间距均标记为生成演武，不作为史实结论。

## 生成链路

1. 在 PC 上离线训练 19x14 的轻量策略，奖励包括出生区安全、阵营连通、路径长度、障碍比例和局部地形兼容性。
2. 安卓端只执行一次 ONNX 推理，输出 266 个格子的地形偏好；模型文件在加载前校验 SHA-256，推理超过 35ms 预算则拒绝该候选。
3. 经典 Simple Tiled WFC 使用最小熵、按权重坍缩和约束传播，消除水地与山障直接相邻的局部冲突。
4. 独立硬校验器检查所有具名出生点可达、保护区可通行、难度对应障碍比例和局部兼容性。
5. 战术代理门禁继续检查双方平均接敌距离差、中线通道数量和出生点机动空间；这些指标只代表基本公平性，不等同于真人乐趣。
6. 最多修复 64 格；仍不合格时回退到已验证模板。种子、模型版本、推理耗时、WFC 尝试、修复数和回退原因随存档保存。
7. “智能推荐”使用可关闭、可删除的三臂 epsilon-greedy 难度老虎机，只更新本地计数与均值，不在手机训练深度网络，并记录真实选择概率。
8. 每场战斗用 `dongzhou-replay-v1` 保存操作时间线、结局原因、耗时、道具、剧情跳过与地图种子；关闭本地记录后不生成回放，也不更新老虎机。

## 开源依据

- 原始 PCGRL 环境与 narrow/wide 表示：<https://github.com/amidos2006/gym-pcgrl>
- 可控 PCGRL 后续实现：<https://github.com/smearle/control-pcgrl>
- 麻隧史料原文：<https://ctext.org/text.pl?if=gb&node=19113&show=parallel>

开源代码用于核对表示和奖励范式；APK 不捆绑这些 Python/JAX 训练框架，仅包含本项目导出的 ONNX 权重和 ONNX Runtime。

## 当前验收

- Python 模型契约与特征复现测试。
- 策略相对随机基线的连通率、总奖励和障碍比例门槛。
- WFC 固定种子复现、相邻兼容、硬校验、有限修复和模板回退测试。
- 360 个种子乘三档难度共 1080 个实际 ONNX 候选全部通过硬校验与战术代理门禁，评估回退率为 0。
- 同一批地图完成 2160 局双向镜像规则代理歼灭战：超时率 0、决胜率 100%、地形唯一率 100%；简单、标准、艰难的平均回合数分别约为 19.50、20.37、22.20。
- 规则代理只证明地图能承载完整交战且没有明显出生侧崩溃，不是 HAPPO 验收，更不能替代真人的趣味和平衡数据。
- 172 关 Web 发布校验、Android lint、APK 签名与模型哈希验包。
- 真实手机的冷启动、P50/P95/P99、峰值内存、发热和降频仍需连接设备后实测，桌面构建结果不能替代这些数据。
