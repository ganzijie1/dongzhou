# 东周列国志关卡合并审计

## 合并原则

同一著名战役尽量只做一关。只有以下四项均连续时才合并：时间连续、地点连续、交战双方连续、战略目标连续。同一回目包含多个不同事件，不作为合并依据。

为避免旧存档因数字 `stage_index` 位移而打不开，新存档写入 `stage_id` 与 `stage_table_version`；旧存档优先按 `metadata.battle_title` 迁移。已删除索引的旧阶段可重开合并后的完整战役，并保留金币、物品与将领培养进度。

## 保留为独立关卡

以下虽处于同一回目或前后相接，但不是同一场战役：

- `03` 镐京陷落 / `03b` 四国复镐：守城败亡与后续诸侯勤王反攻，交战阵营与战略目标改变。
- `07` 戴城夜袭 / `07b` 许都夺城：地点不同。
- `11a` 鲁郑伐宋 / `11b` 纪城大战 / `11c` 东郊反杀：三次独立军事或政变行动。
- `20a` 至 `20d`：伐卫、伐骊戎、灭狄霍魏、楚宫靖难，完全不同事件。
- `21a` 至 `21c`：孤竹战争的三个地理阶段，但各自有独立战场目标；当前属于长距离远征，不是同一战场的连续阶段。
- `24a` 新密围城 / `24b` 许城解围：不同城池和战斗目标。
- `25a` 下阳破关 / `25b` 箕山袭虞：灭虢与袭虞是先后两个国家、两个目标。
- `30a` 缘陵救杞 / `30b` 韩原大战：时间、地点、交战方不同。
- `34a` 睢阳守城 / `34b` 泓水败阵：独立战争。
- `36a` 令狐破城 / `36b` 绛宫火变：野战与宫变不同。
- `38a` 王城突围 / `38b` 温原勤王：救周与讨温原叛军是不同任务。
- `43a` 九国围许 / `43b` 秦晋围郑：相隔一年，围攻对象分别为许国和郑国。
- `45a` 崤山伏击 / `45b` 箕城御翟：秦晋战争与翟人战争不同。
- `46a` 大谷之战 / `46b` 彭衙之战 / `46c` 王官破城：秦晋多年间的三次战役。
- `47a` 长翟之战 / `47b` 令狐夜袭：敌人和地点不同。
- `48a` 郑境诱营 / `48b` 河曲之战：诱士会归晋与秦晋野战是不同任务。
- `50a` 大棘之战 / `50b` 焦城解围 / `50c` 桃园脱险：宋国内战、秦晋围城、晋国宫廷事件不同。
- `53a` 株林讨逆 / `53b` 皇门破郑：讨陈与伐郑不同。
- `55a` 睢阳围城 / `55b` 青草坡之战：楚宋战争与秦晋战争不同。
- `56a` 新筑夜袭 / `56b` 鞌之战：前者为卫齐冲突，后者为晋鲁卫曹联军与齐国决战，时间和参战目标均不同。

## 后续约束

新增章节遇到同一著名战役跨回目时，优先在一张大地图内使用阶段状态机完成；只有玩家阵营切换、跨越多年或地点无法合理同图表达时才拆关。拆关必须在剧情与文档中写明理由。
