# Backward Reachable Tube 与追逃博弈：HJI 可达性、数值算法与游戏应用

## 摘要

Backward Reachable Tube，简称 BRT，研究这样一个问题：从哪些初始状态出发，系统会在给定时间窗口内进入目标集合。目标集合可以是碰撞区、死亡区、越界区、拦截区，也可以是必须到达的终点区。BRT 不只预测某一条轨迹，而是同时考虑连续动力学、控制约束、对手行为和最坏扰动，得到整个状态空间中的可达区域。

追逃博弈是 BRT 最典型的应用。逃方试图避免捕获，追方试图在有限时间内迫使逃方进入捕获集合。双方的最优对抗通过 Hamilton-Jacobi-Isaacs 方程刻画；BRT 则是相应价值函数的零水平集或负水平集。

本文统一介绍后向可达集、后向可达管、可生存核、HJI 变分不等式、Isaacs 条件、Level Set 数值方法、半拉格朗日方法、追逃策略提取、多人追逃、地图障碍和 5v5 游戏中的安全控制。全文采用统一符号约定：

$$V(t,x)\leq 0$$

表示状态 $x$ 在剩余时间窗口内属于失败 BRT，即追方或扰动可以迫使系统进入目标集合。

## 一、为什么需要集合而不是单条预测轨迹

普通轨迹预测固定双方策略后计算：

$$\dot x=f(x,u,d)$$

其中 $u$ 是己方控制，$d$ 是对手或扰动。若未来控制并不确定，单条预测轨迹只能回答“按照当前假设会发生什么”，不能回答“最坏情况下是否仍然安全”。

BRT 回答更强的问题：

1. 对手是否存在一种策略，可以在时限内迫使己方失败；
2. 己方是否存在一种策略，可以对所有允许的对手动作保持安全；
3. 当前状态距离不可挽回区域还有多少裕量；
4. 哪些控制会把系统推向 BRT，哪些控制可以把系统推出 BRT。

因此，BRT 既是分析工具，也是运行时安全控制器的基础。

## 二、受控动力系统

考虑连续时间系统：

$$\dot x(s)=f(x(s),u(s),d(s))$$

状态为：

$$x(s)\in\mathbb R^n$$

控制与扰动分别满足：

$$u(s)\in\mathcal U,\qquad d(s)\in\mathcal D$$

从时刻 $t$ 的状态 $x$ 出发，轨迹记为：

$$\xi(s;t,x,u,d)$$

通常假设 $f$ 对状态局部 Lipschitz，控制集合和扰动集合紧，从而给定可测输入后轨迹存在且唯一。

在追逃问题中，可以把 $u$ 理解为逃方控制，把 $d$ 理解为追方控制；在安全控制问题中，$d$ 也可以表示风场、模型误差或其他玩家的对抗动作。

## 三、目标集合与隐式曲面

令目标集合为：

$$\mathcal L=\{x:l(x)\leq 0\}$$

函数 $l(x)$ 称为目标函数或隐式曲面函数。常见选择是带符号距离。

若捕获发生在追逃距离不超过 $R$ 时，则：

$$l(x_E,x_P)=\lVert x_E-x_P\rVert-R$$

捕获集合为：

$$\mathcal L=\{(x_E,x_P):\lVert x_E-x_P\rVert\leq R\}$$

若目标是障碍物集合，也可以令 $l(x)$ 为到障碍边界的带符号距离，使障碍内部取负值。

## 四、Backward Reachable Set

Backward Reachable Set，简称 BRS，关注终端时刻是否进入目标集合。给定终端时刻 $0$ 和起始时刻 $t<0$，失败型 BRS 可写为：

$$\mathcal R(t)=\{x:\exists d(\cdot),\ \forall u(\cdot),\ \xi(0;t,x,u,d)\in\mathcal L\}$$

在微分博弈中，为避免追方预知逃方未来动作，严格定义通常使用非预见策略。令：

$$\gamma:\mathcal U_{[t,0]}\rightarrow\mathcal D_{[t,0]}$$

且当两条控制在时刻 $s$ 前相同时，$gamma$ 产生的扰动也必须在 $s$ 前相同。于是：

$$\mathcal R(t)=\{x:\exists\gamma,\ \forall u(\cdot),\ \xi(0;t,x,u,\gamma[u])\in\mathcal L\}$$

BRS 只检查终端时刻，不关心此前是否曾经进入目标集合。

## 五、Backward Reachable Tube

BRT 关注整个时间窗口内是否曾经进入目标集合：

$$\mathcal V(t)=\{x:\exists\gamma,\ \forall u(\cdot),\ \exists s\in[t,0],\ \xi(s;t,x,u,\gamma[u])\in\mathcal L\}$$

这一区别非常重要。若角色在中途被捕获，随后又因数值积分或复活规则离开捕获区，终端 BRS 可能漏掉失败；BRT 不会漏掉窗口中的首次进入事件。

在安全问题中，BRT 通常被解释为有限时域不可避免集：一旦状态进入该集合，对手就存在迫使系统在时限内触碰失败集的策略。

## 六、BRS 与 BRT 的区别

BRS 的终端代价为：

$$J_{\mathrm{BRS}}(t,x,u,d)=l(\xi(0;t,x,u,d))$$

BRT 的路径代价为：

$$J_{\mathrm{BRT}}(t,x,u,d)=\min_{s\in[t,0]}l(\xi(s;t,x,u,d))$$

因此：

$$\mathcal R(t)=\{x:V_{\mathrm{BRS}}(t,x)\leq0\}$$

$$\mathcal V(t)=\{x:V_{\mathrm{BRT}}(t,x)\leq0\}$$

对于吸收型失败集合，进入后永远保持失败，BRS 与 BRT 可能一致；对于可离开的目标集合，两者一般不同。

## 七、追逃博弈价值函数

采用“逃方最大化安全裕量，追方最小化安全裕量”的约定，BRT 价值函数定义为：

$$V(t,x)=\inf_{\gamma}\sup_{u(\cdot)}\min_{s\in[t,0]}l(\xi(s;t,x,u,\gamma[u]))$$

若：

$$V(t,x)>0$$

则逃方存在保持在目标集合外的策略。若：

$$V(t,x)\leq0$$

则追方存在在时限内完成捕获的非预见策略。

上式定义的是下价值。交换双方行动顺序可得到上价值。只有在 Isaacs 条件成立时，两者才必然一致。

## 八、Hamiltonian

令协态或空间梯度为：

$$p=\nabla_xV(t,x)$$

与上述下价值相匹配的 Hamiltonian 为：

$$H^{-}(x,p)=\min_{d\in\mathcal D}\max_{u\in\mathcal U}p^{\mathsf T}f(x,u,d)$$

上价值对应：

$$H^{+}(x,p)=\max_{u\in\mathcal U}\min_{d\in\mathcal D}p^{\mathsf T}f(x,u,d)$$

一般总有：

$$H^{-}(x,p)\geq H^{+}(x,p)$$

若控制符号约定相反，极值顺序也会相应改变。实现中必须让价值函数、集合符号和 Hamiltonian 的极值方向完全一致。

## 九、Isaacs 条件

Isaacs 条件要求：

$$\min_{d\in\mathcal D}\max_{u\in\mathcal U}p^{\mathsf T}f(x,u,d)=\max_{u\in\mathcal U}\min_{d\in\mathcal D}p^{\mathsf T}f(x,u,d)$$

条件成立时：

$$H^{-}(x,p)=H^{+}(x,p)$$

追逃博弈具有统一价值函数。若条件不成立，上下价值之间可能存在间隙，需要明确谁先行动、谁能观察谁，以及是否允许混合策略或松弛控制。

## 十、HJI 方程

终端 BRS 的价值函数满足 Hamilton-Jacobi-Isaacs 方程：

$$\frac{\partial V}{\partial t}+H(x,\nabla V)=0$$

终端条件为：

$$V(0,x)=l(x)$$

由于价值函数可能不可微，解通常按照黏性解理解。黏性解允许零水平集在形成尖角、激波和拓扑变化时仍保持良好定义。

## 十一、BRT 的 HJI 变分不等式

BRT 必须记住“已经进入过目标集”的事实。其常见变分不等式为：

$$\min\left\{\frac{\partial V}{\partial t}+H(x,\nabla V),\ l(x)-V(t,x)\right\}=0$$

终端条件仍为：

$$V(0,x)=l(x)$$

约束：

$$V(t,x)\leq l(x)$$

保证价值函数不会忘记此前已触及目标集合。数值实现中常在每个反向时间步做：

$$V\leftarrow\min\{V,l\}$$

## 十二、离散时间动态规划

若系统离散化为：

$$x_{k+1}=F(x_k,u_k,d_k)$$

则失败 BRT 可通过反向递推近似：

$$V_N(x)=l(x)$$

$$V_k(x)=\min\left\{l(x),\ \min_{d\in\mathcal D}\max_{u\in\mathcal U}V_{k+1}(F(x,u,d))\right\}$$

如果双方控制集合有限，该式可直接枚举；连续控制集合则需要解析极值、优化器或控制离散化。

## 十三、单积分器追逃

考虑平面单积分器：

$$\dot x_E=v_Eu_E,\qquad\lVert u_E\rVert\leq1$$

$$\dot x_P=v_Pu_P,\qquad\lVert u_P\rVert\leq1$$

定义相对位置：

$$r=x_E-x_P$$

相对动力学为：

$$\dot r=v_Eu_E-v_Pu_P$$

捕获目标函数为：

$$l(r)=\lVert r\rVert-R$$

对应 Hamiltonian 为：

$$H(r,p)=\max_{\lVert u_E\rVert\leq1}\min_{\lVert u_P\rVert\leq1}p^{\mathsf T}(v_Eu_E-v_Pu_P)$$

由于两项可分离：

$$H(r,p)=(v_E-v_P)\lVert p\rVert$$

当 $v_P>v_E$ 且平面无遮挡时，追方可以缩短距离，理想捕获时间为：

$$T_{\mathrm{cap}}=\frac{\lVert r_0\rVert-R}{v_P-v_E}$$

该闭式结论依赖无限平面、速度瞬时转向和无遮挡等强假设；存在转弯半径、加速度、障碍或安全区时必须重新求解。

## 十四、最优方向

当 $p\neq0$ 时，逃方最大化：

$$p^{\mathsf T}v_Eu_E$$

所以：

$$u_E^{\star}=\frac{p}{\lVert p\rVert}$$

追方最小化：

$$-p^{\mathsf T}v_Pu_P$$

所以：

$$u_P^{\star}=\frac{p}{\lVert p\rVert}$$

在无障碍单积分器中，双方都沿价值梯度方向运动，但物理效果不同：逃方增加安全价值，追方降低相对距离。更一般动力学下应直接对 Hamiltonian 求极值，不能机械套用归一化梯度。

## 十五、双积分器追逃

若需要显式建模速度与加速度，可写为：

$$\dot q_E=v_E,\qquad\dot v_E=a_E$$

$$\dot q_P=v_P,\qquad\dot v_P=a_P$$

相对状态为：

$$x=(q_E-q_P,v_E-v_P)$$

相对动力学为：

$$\dot x=(v_E-v_P,\ a_E-a_P)$$

捕获条件仍可只依赖位置，但速度会影响未来可达性。因此，位置相同的两个状态可能因相对速度不同而分别位于 BRT 内外。

## 十六、Dubins 追逃

固定速度且受转向率约束的角色可建成 Dubins 动力学：

$$\dot x=v\cos\theta$$

$$\dot y=v\sin\theta$$

$$\dot\theta=\omega,\qquad\lvert\omega\rvert\leq\omega_{\max}$$

追逃相对状态至少包含相对位置与双方朝向。相比单积分器，Dubins 追逃会出现明显的转弯半径效应：距离很近也不一定立即可捕获，距离较远也可能因朝向优势而进入 BRT。

## 十七、状态约束与障碍

设允许区域为：

$$\mathcal K=\{x:g(x)\geq0\}$$

障碍或越界失败集合为：

$$\mathcal O=\{x:g(x)\leq0\}$$

若捕获和碰撞都算失败，可构造联合目标：

$$l_{\mathrm{joint}}(x)=\min\{l_{\mathrm{capture}}(x),g(x)\}$$

若障碍只限制运动而不直接判负，则应把它放进可行控制和状态约束，而不是简单并入失败目标。两种语义不能混用。

## 十八、可生存核

可生存核是存在控制使系统永远留在安全集中的状态集合：

$$\mathrm{Viab}(\mathcal K)=\{x_0:\exists u(\cdot),\ \forall t\geq0,\ x(t)\in\mathcal K\}$$

在确定性、无限时域、互补目标和一致信息结构等条件下，可生存核可与失败 BRT 的补集联系起来。但有限时域 BRT、随机动力学和不同控制量词下，这种互补关系不一定精确成立。

## 十九、Level Set 表示

HJI 可达性通常不显式存储集合边界，而是存储标量场：

$$\mathcal V(t)=\{x:V(t,x)\leq0\}$$

边界为：

$$\partial\mathcal V(t)=\{x:V(t,x)=0\}$$

Level Set 表示允许集合自然分裂、合并和产生孔洞，不需要显式跟踪边界拓扑。

## 二十、空间离散与迎风差分

对每个状态维度建立网格。为了与信息传播方向一致，空间梯度应使用迎风差分。以一维为例：

$$D^-V_i=\frac{V_i-V_{i-1}}{\Delta x}$$

$$D^+V_i=\frac{V_{i+1}-V_i}{\Delta x}$$

Hamiltonian 数值通量根据特征速度选择左导数或右导数。简单中心差分通常会在不可微位置产生振荡。

## 二十一、Lax-Friedrichs 数值 Hamiltonian

局部 Lax-Friedrichs 通量可写为：

$$\widehat H=H\left(x,\frac{p^-+p^+}{2}\right)-\frac{1}{2}\sum_i\alpha_i(p_i^+-p_i^-)$$

其中：

$$\alpha_i\geq\sup\left\lvert\frac{\partial H}{\partial p_i}\right\rvert$$

耗散项提高单调性和稳定性，但过大的 $\alpha_i$ 会使边界过度扩散。

## 二十二、CFL 条件

显式时间推进需满足 CFL 条件。典型形式为：

$$\Delta t\sum_i\frac{\alpha_i}{\Delta x_i}\leq C_{\mathrm{CFL}}$$

若时间步过大，零水平集可能越过多个网格单元并导致数值不稳定。高阶 Runge-Kutta 只能改善时间精度，不能取消 CFL 限制。

## 二十三、半拉格朗日方法

离散时间动态规划可以使用半拉格朗日更新：

$$V_k(x_i)=\min\left\{l(x_i),\min_d\max_u\mathcal I[V_{k+1}](x_i+\Delta t f(x_i,u,d))\right\}$$

$\mathcal I$ 表示网格插值。半拉格朗日方法通常允许比显式有限差分更大的时间步，但插值误差、控制离散化和非单调高阶插值仍需审计。

## 二十四、边界条件

计算域有限时必须规定网格边界外的语义。常见选择包括：

1. 外推价值；
2. 设置为失败；
3. 设置为安全；
4. 周期边界；
5. 反射边界。

边界条件直接改变 BRT。若计算域过小，错误边界会比网格离散误差更严重。

## 二十五、维数灾难

若每个维度使用 $N$ 个网格点，$n$ 维网格规模为：

$$N^n$$

这就是 HJI 可达性的维数灾难。常见缓解方法包括：

1. 使用相对坐标和对称性降维；
2. 对动力学做子系统分解；
3. 只在窄带或自适应网格上更新；
4. 使用稀疏网格；
5. 用可验证误差界的函数近似；
6. 在线只查表和插值，离线完成高成本求解。

神经网络拟合价值函数可以扩展维度，但若没有保守误差界、残差界或形式化验证，不能把拟合零水平集直接称为安全证书。

## 二十六、从价值函数提取追方策略

追方控制可由 Hamiltonian 最小化得到：

$$d^{\star}(t,x)\in\arg\min_{d\in\mathcal D}\max_{u\in\mathcal U}\nabla V(t,x)^{\mathsf T}f(x,u,d)$$

逃方安全控制可由：

$$u^{\star}(t,x)\in\arg\max_{u\in\mathcal U}\min_{d\in\mathcal D}\nabla V(t,x)^{\mathsf T}f(x,u,d)$$

若梯度接近零、价值函数不可微或控制极值不唯一，应保留候选集合或使用正则化破同分，而不是依赖任意数组顺序。

## 二十七、安全控制集合

采用 $V>0$ 为安全的约定。在边界 $V=0$ 上，保持安全需要存在控制使最坏扰动下价值不下降：

$$\mathcal U_{\mathrm{safe}}(t,x)=\left\{u\in\mathcal U:\min_{d\in\mathcal D}\left(\frac{\partial V}{\partial t}+\nabla V^{\mathsf T}f(x,u,d)\right)\geq0\right\}$$

若名义策略给出 $u_{\mathrm{nom}}$，可求最小修正：

$$u_{\mathrm{shield}}\in\arg\min_{u\in\mathcal U_{\mathrm{safe}}}\lVert u-u_{\mathrm{nom}}\rVert^2$$

这形成 reachability safety shield。安全集合为空时，系统已经没有满足当前模型保证的控制，应触发明确的不可恢复状态，而不是伪造安全动作。

## 二十八、BRT 裕量与风险排序

价值函数本身可以作为安全裕量：

$$m(t,x)=V(t,x)$$

当 $m$ 为正且远离零时，状态具有较大模型内安全余量；当 $m$ 接近零时，需要提高安全控制权重；当 $m$ 为负时，追方存在模型内必达策略。

但不同地图、不同缩放或不同目标函数得到的数值不一定可直接比较。若 $l$ 不是带符号距离，$V$ 的绝对大小也不等于真实物理距离。

## 二十九、有限时域与无限时域

有限时域 BRT 随剩余时间增加通常单调扩张：

$$\mathcal V(t_1)\subseteq\mathcal V(t_2),\qquad t_1>t_2$$

若反向时间继续延长并收敛，可得到无限时域固定点：

$$V_{\infty}(x)=\lim_{t\rightarrow-\infty}V(t,x)$$

数值上应使用集合变化、价值残差和策略稳定性共同判断收敛，不能只凭迭代次数。

## 三十、随机追逃与概率可达性

若动力学包含扩散：

$$dX_t=f(X_t,u_t,d_t)dt+\sigma(X_t)dW_t$$

价值方程出现二阶项：

$$\frac{\partial V}{\partial t}+H(x,\nabla V)+\frac{1}{2}\mathrm{tr}\left(\sigma\sigma^{\mathsf T}\nabla^2V\right)=0$$

此时可以研究捕获概率、风险敏感代价或机会约束。确定性 BRT 与概率达到阈值的集合不是同一对象，必须标明使用的是最坏情况保证还是概率保证。

## 三十一、多人追逃

设有 $M$ 个追方和 $N$ 个逃方。联合状态维数会快速增长。捕获任一逃方的目标可写为：

$$l_{\mathrm{any}}(x)=\min_{i,j}\left(\lVert x_{E_i}-x_{P_j}\rVert-R_{ij}\right)$$

要求捕获全部逃方则需要记录捕获状态或构造混合逻辑，不能简单把所有距离取最大值后忽略已捕获对象。

工程上常把多人问题分为两层：

1. 高层使用匹配、分配或图博弈决定谁追谁；
2. 低层使用低维两人或小组 BRT 提供拦截可行性和安全裕量。

这种分解降低计算量，但通常只提供近似保证。若多个追方的协同捕获不可分解，必须显式建模联合状态。

## 三十二、追逃分配

令第 $i$ 个追方拦截第 $j$ 个逃方的代价为：

$$c_{ij}=\phi(V_{ij}(t,x_{ij}))$$

其中 $V_{ij}$ 是成对 BRT 价值，$\phi$ 把安全裕量转换为分配代价。可解线性分配：

$$\min_{z_{ij}}\sum_{i,j}c_{ij}z_{ij}$$

满足：

$$\sum_jz_{ij}\leq1,\qquad\sum_iz_{ij}\leq1,\qquad z_{ij}\in\{0,1\}$$

若需要多追一、区域防守或角色能力互补，应改用容量匹配、超图匹配或混合整数模型。

## 三十三、信息不完全

若追方位置或意图不可完全观测，系统状态应扩展为 belief：

$$b_t(x)=\mathbb P(X_t=x\mid\mathcal Y_t)$$

在 belief 空间直接求 HJI 通常维度极高。可选近似包括：

1. 对置信集内状态求鲁棒 BRT；
2. 对若干 belief 情景求概率可达性；
3. 使用集合滤波先构造状态包络，再对包络做最坏情况可达分析。

仅把状态估计均值代入确定性 BRT 会忽略估计尾部，不能提供同等安全保证。

## 三十四、模型误差与鲁棒化

若真实动力学为：

$$\dot x=f_{\mathrm{nom}}(x,u,d)+w$$

且：

$$w\in\mathcal W$$

可把 $w$ 并入扰动集合：

$$\widetilde d=(d,w)$$

得到对误差集合 $\mathcal W$ 的鲁棒 BRT。误差集合过小会产生虚假安全，过大会导致过度保守。应使用独立回放残差、系统辨识误差和分布漂移测试校准，而不是凭经验随意设置。

## 三十五、5v5 游戏状态设计

完整 5v5 状态不适合直接建立均匀 HJI 网格。更可行的低维局部状态包括：

$$x=(\Delta p_x,\Delta p_y,\Delta v_x,\Delta v_y,h_E,h_P,c_E,c_P)$$

其中相对位置和速度描述追逃几何，$h$ 表示关键生命资源，$c$ 表示关键技能或控制状态。

还可以按任务构造不同 BRT：

1. 被单人追击时的逃生 BRT；
2. 越塔或进入敌方火力圈的失败 BRT；
3. 救援队友时的拦截 BRT；
4. 争夺目标时的抢先到达 BRT；
5. 团战脱离时的安全走廊 BRT。

不要把所有英雄、技能和地图信息无差别塞入同一网格。应先确定决策问题，再保留影响短时可达性的最小充分状态。

## 三十六、技能与混合动力学

位移技能、控制免疫、减速、眩晕和传送会改变动力学模式。可引入离散模式：

$$m\in\mathcal M$$

并写成混合系统：

$$\dot x=f_m(x,u,d)$$

技能触发产生模式跳转：

$$m^+=G(m,a,e)$$

对应问题属于 hybrid reachability。若技能次数和冷却离散状态很少，可以对各模式建立耦合价值函数；若模式很多，需要符号缩约、分层规划或近似动态规划。

## 三十七、地图与导航的组合

BRT 处理短时动力学安全，导航算法处理长距离几何路径。推荐组合为：

1. A-star、PRM 或导航网格生成全局候选路径；
2. 局部控制器跟踪候选路径；
3. BRT safety shield 检查局部追逃与碰撞风险；
4. 进入 BRT 边界时修改局部控制或重新规划；
5. 所有动作继续通过游戏原生合法动作与碰撞检查。

BRT 不是全局路径规划器，A-star 也不能替代连续动力学下的对抗可达性。

## 三十八、离线计算与在线查询

典型部署流程是：

1. 离线定义动力学、目标集合、控制集合和扰动集合；
2. 在相对状态网格上反向求解 HJI；
3. 保存不同时间层的价值函数或收敛固定点；
4. 在线把观测映射到相对状态；
5. 多线性插值得到 $V$ 与 $\nabla V$；
6. 在接近边界时启动安全控制；
7. 记录查询状态、裕量、候选动作和最终动作用于回放审计。

在线插值必须处理越界状态。静默截断到网格边缘可能把域外危险状态误判为安全。

## 三十九、数值验证

至少需要以下验证：

1. 网格加密后零水平集是否稳定；
2. 时间步减小后结果是否收敛；
3. 解析可解样例是否复现闭式边界；
4. 从 BRT 内采样时，追方策略是否能稳定完成捕获；
5. 从 BRT 外采样时，安全策略是否能在规定时域内避免捕获；
6. 对手策略是否覆盖理论最坏方向；
7. 模型误差、延迟和插值误差下保证是否仍成立；
8. 域边界条件是否影响关注区域。

蒙特卡洛成功率不能单独证明最坏情况保证，但可以发现动力学实现、符号方向和策略提取中的错误。

## 四十、常见错误

### 1. 混淆 BRS 与 BRT

只检查终端状态却声称覆盖整个时间窗口，会漏掉中途进入失败集合的轨迹。

### 2. 极值顺序错误

$\min\max$ 与 $\max\min$ 对应不同信息结构。代码中调换顺序可能把追方优势变成逃方优势。

### 3. 集合符号反转

若一处使用 $V\leq0$ 为失败，另一处使用 $V\geq0$ 为失败，安全控制器会朝错误方向工作。

### 4. 忽略控制约束

使用无限加速度或瞬时转向模型得到的 BRT，不能直接用于有冷却、转向率和动作前摇的角色。

### 5. 把近似网络当作证书

低平均误差不保证零水平集附近误差小。安全用途必须单独验证边界误差和最坏残差。

### 6. 把 BRT 当成必然预测

进入 BRT 表示对手存在一种可迫使失败的策略，不表示实际对手一定会选择该策略。

## 四十一、与其他数学模块的连接

BRT 与现有游戏数学模块可形成以下组合：

1. 与 Viability Kernel 联合，区分有限时域失败和无限时域可生存性；
2. 与 CBF 联合，把离线 BRT 价值转换为在线安全约束；
3. 与 POMDP 和粒子滤波联合，处理隐藏追方状态；
4. 与鲁棒 MDP 联合，处理高层离散策略和低层连续安全；
5. 与匹配博弈联合，解决多人追逃分配；
6. 与 PDMP 联合，处理技能、死亡、复活和模式跳转；
7. 与概率模型检测联合，审计离散抽象后的时限安全性质；
8. 与敏感性分析联合，识别速度、延迟和技能参数对 BRT 体积的影响。

## 四十二、建议的游戏接口

离线求解器应输出：

1. 状态维度和归一化规则；
2. 时间网格与空间网格；
3. 价值数组；
4. 梯度或可重复计算梯度的方法；
5. 目标函数与符号约定；
6. 控制和扰动边界；
7. 域边界条件；
8. 数值误差与验证报告。

在线接口至少返回：

$$\left(V,\nabla V,u_{\mathrm{safe}},\mathrm{inside},\mathrm{out\_of\_domain}\right)$$

其中 `inside` 表示是否位于失败 BRT，`out_of_domain` 必须单独报告，不能把域外查询伪装成正常插值。

## 四十三、最小实现路线

第一阶段选择二维相对位置单积分器，复现圆形 BRT 和闭式捕获时间。

第二阶段加入相对速度，构造四维双积分器 BRT，验证制动距离和捕获边界。

第三阶段加入地图局部障碍、延迟和有限控制集合，比较有限差分与半拉格朗日结果。

第四阶段把成对 BRT 接入追逃匹配，只允许其修改候选优先级，不绕过合法动作。

第五阶段加入回放反事实测试，验证触发 safety shield 前后的捕获率、任务成功率和控制抖动。

## 四十四、结论

Backward Reachable Tube 把“对手能否在时限内迫使失败”转化为状态空间中的集合计算。追逃博弈通过 HJI 方程把双方最优对抗压缩进 Hamiltonian，Level Set 方法则允许捕获边界自然变形和改变拓扑。

其核心价值不在于生成一条看似合理的追逐轨迹，而在于提供量词明确的最坏情况边界、可提取的安全控制和可审计的数值误差。游戏接入时，应优先使用相对状态降维、离线计算与在线查表，并把 BRT 作为策略候选和安全盾，而不是替代原生规则、碰撞、资源和联合规划。
