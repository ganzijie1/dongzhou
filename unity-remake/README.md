# 东郊索命 Unity 重制

这是《东周列国志》第一回“东郊索命”的独立 Unity 2022.3 LTS 可玩原型。工程直接打开战场，不含启动页。

## 运行

1. 用 Unity Hub 添加本目录，使用 Unity 2022.3 LTS 打开。
2. 打开 `Assets/Scenes/DongJiao.unity`，进入 Play Mode。
3. 左键选择、移动和攻击；鼠标滚轮缩放，中键或右键拖动画面；侧栏按钮可结束回合、用药、切换网格和重开。

## 已实现

- 原版 19 x 14 地形、东郊地图、部署、18 回合限制与七名王师敌军。
- 杜伯、左儒死亡判负，清除王师获胜。
- 可达范围、阻挡、近战、反击、敌军寻路回合、补给点和物品。
- 杜伯接近周宣王后的史实单挑，以及开场、胜利、失败剧情。
- 分辨率自适应界面、镜头缩放与拖拽、战斗记录和 EditMode 规则测试。
